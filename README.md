# 🔀 GlobalFX - Real-Time Currency Converter App

[![Live Demo](https://img.shields.io/badge/Live_Demo-Interactive_API_App-00F2FE?style=for-the-badge&logo=github)](https://af023.github.io/Global-currency-converter-app/)

## 📌 Overview
GlobalFX is an interactive **Real-Time Currency Exchange Web Application** built with HTML5, Tailwind CSS, and asynchronous JavaScript (`async/await`, `fetch`). 

The application integrates with public financial exchange rate APIs to perform instant multi-currency conversions, error handling, live loading states, and dynamic bilingual (PT/EN) internationalization.

---

## ✨ Key Features
- **Live Financial API Integration:** Asynchronous data fetching (`open.er-api.com`) providing up-to-date international exchange rates.
- **Instant Swap & Conversion:** Real-time rate calculations upon user input or currency pairing toggle.
- **Bilingual Switcher (i18n):** Seamless translation engine between English and Portuguese.
- **Glassmorphism Visual UX:** Modern frosted glass design panels, neon accents, and responsive layout.
- **Error & Loading States:** Built-in fallback indicators and loading feedback during API calls.

---

## 🛠️ Tech Stack
- **Markup:** HTML5 (Semantic).
- **Styling:** Tailwind CSS (Glassmorphism layout).
- **Logic & API:** Asynchronous JavaScript (`Fetch API`, `async/await`, DOM manipulation).
- **Icons:** Lucide Icons.
